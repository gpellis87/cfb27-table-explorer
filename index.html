About this view

Click a table for its schema — stable numeric ID, field list, one real example value per field — and, where available, every real record in that table, with its own search box.

Table names/IDs/fields come from the game's schema, not any one save, so they're identical no matter whose save you read. Only the records themselves are specific to this save.

A table split across multiple physical chunks in the save (common for stat/history tables — PlayerStatRecord spans 36) is merged: every populated chunk's rows are included below, not just the largest one.

Explore it yourself

  • An actual CFB27 dynasty save file
  • Patience for multi-chunk tables: same table name can mean several physical chunks with genuinely different rows in each, not backups — check them all, not just the biggest
